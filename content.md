# Building a world where data can be **verified** and **computed privately.**

Primus builds the decentralized verification and privacy layer, by proving the authenticity of any data off-chain, and computing the encrypted private data on-chain.

- Mission: Privacy and Verifiability
- Techniques: ZKTLS/FHE
- Chain: Base / BNB Chain
- Audience: The Global


## Why We Are Building Primus 

The world’s most valuable data remains locked in Web2 systems, lacking a trusted way to verify it and unlock its value on-chain.

### Primus builds the verification and privacy network with zkTLS and FHE techniques  [Mission]
> zkTLS: An attestor cryptographically proves the authenticity of Internet data or API responses obtained through HTTPS/TLS, without accessing the underlying raw data. FHE: Enables computation directly on encrypted data, producing results that can only be decrypted and accessed by the authorized data owner.

## The Problems, and The Solutions


### Internet data, including users’ private data, is hard to verify and to be used without breaking user privacy  [Problems]
> The most valuable data, users’ private data, requires a secure way to be verified and then be processed and computed in the smart contract


### State-of-the-art cryptography can solve the data verifiability and privacy problems in a trustless and secure way [Solutions]
> Primus creates a cryptographic data verification and computation network, allowing the user or agent to prove the authenticity of any HTTPs data and interactions. The private data can be first encrypted, and then completely processed for any tasks through the Primus FHE computing engine.



### Why Primus uses the cryptography as the core method [Reasons]
- Primus zkTLS enables verifiable Internet data without compromising user privacy during proof generation, while delivering up to 10× higher performance than existing protocols.
- Primus FHE leverages the SOTA algorithms and accelerates the whole adoption with GPU power, delivering an optimal balance between performance and cost.
- Primus Network leverages Trusted Execution Environments (TEEs) to protect runtime execution and sensitive cryptographic materials, providing an additional layer of security across the entire system.
